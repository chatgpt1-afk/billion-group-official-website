# Billion Group Corporate Website — V4 Redesign Preview

Open `index.html` in Chrome. No installation, server, framework or database is needed.

## What changed
- Replaced product listing, item prices, sorting and shopping cart with corporate-focused content.
- Rebuilt the homepage and navigation; added original SVG delivery-truck milestone timeline.
- Seven milestone years sourced from https://www.billiongroup.com.my/about/
- Added Billion, Pantai Timor, own-label brand, regional promotion, outlet, career and contact pages.
- Mobile-first breakpoints and accessible milestone controls.

## Source and media limitations
Official content is paraphrased from billiongroup.com.my (About, Billion, Pantai Timor, Billion Brand, Promotions, Contact, Home). The original website currently contains changing figures and some inconsistencies: the About page references 56 outlets, the timeline references a 53rd outlet in 2024. This preview does not assert a current outlet count. The 40+ years figure is a year-based summary from the founding year 1985.

The build environment could not fetch and bundle the official website's image files, so **no official photographs have been downloaded or falsely claimed to be included**. Visual blocks are original CSS illustrations or intentional placeholders. The official site is linked for source photos and current promotional material. To add photographs locally, place approved images in `assets/` and reference them in the page markup.
